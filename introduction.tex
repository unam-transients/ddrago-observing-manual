\chapter{Introduction}

This observing manual describes the DDRAGO instrument on the COLIBRÍ telescope and the process for observing with it.
Chapter \ref{chapter:description} describes the instrument.
Chapter \ref{chapter:observing} describes the observing process: requesting time, planning observing blocks, and receiving data.
The remaining chapters give a technical description of the instrument.

The latest release of this manual is available in PDF at:

\begin{quote}
    \url{https://github.com/unam-transients/ddrago-observing-manual/blob/main/PDF.md}
\end{quote}

Users should always refer to the latest online version of the manual. In the
event of any discrepancy between this PDF and the online version, the latest
online version shall prevail.
